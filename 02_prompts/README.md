# Prompt Engineering + Research Tool App
 
Dynamic prompt implementation with
Streamlit UI — first deployed AI application.
 
## What I Built
1. Static Prompts — fixed template
2. Dynamic Prompts — user input variables
3. Research Tool — Streamlit web application
 
## Research Tool Features
- Clean web interface using Streamlit
- User enters any research topic
- Dynamic prompt built from input
- Gemini LLM generates research summary
- Real time response display
 
## What I Learned
- Static vs Dynamic PromptTemplates
- How variables inject into prompts
- Streamlit basics for AI app UI
- Connecting LangChain to frontend
 
## Tech Stack
Python | LangChain | Google Gemini
Streamlit | PromptTemplate
 
## Run The App
streamlit run research_tool.py
 
## Key Insight
Dynamic prompts = reusable AI components
Same template, different inputs,
different outputs — scalable AI design
