# Chat Models in LangChain
 
Modern conversation-style LLM interaction
using message-based architecture.
 
## What I Learned
- Chat Models vs base LLMs
- System + Human + AI message structure
- Why Chat Models are industry standard
- Model agnostic implementation in LangChain
 
## Models Used
- Google Gemini (ChatGoogleGenerativeAI)
- HuggingFace API (open source)
 
## Key Insight
Switching from Gemini to HuggingFace
required minimal code change —
proving LangChain's abstraction power.
This is model agnostic architecture.
 
## Why I Used Gemini Instead of OpenAI
Course used OpenAI — independently researched
and implemented Gemini free tier, then extended
to HuggingFace open source models.
