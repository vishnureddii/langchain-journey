# Conversational Chatbot — Streamlit + LangChain
 
Full conversational AI chatbot with
persistent chat history using Streamlit.
 
## Key Concepts
- st.session_state for chat persistence
- HumanMessage + AIMessage schema
- st.chat_message for chat UI
- Full conversation history passed to LLM
 
## Why This Matters
Foundation of every chatbot application
RAG chatbot, Agent chatbot —
all use this same pattern
 
## Run
streamlit run chatbot.py
